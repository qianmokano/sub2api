# 两站账户面板统一：sub2api 实施记录

日期：2026-10-03。起点为已合并的 fork main `81bcf3a`，在现有本地仓库的 `kano/account-panel-unification` 分支实施。用户已授权两站代码、PR、镜像及上线，顺序为 sub2api、dujiao；Casdoor 复用现有账户中心。本记录不包含运行凭据。

## 依据与边界

- 复用 `.4` 已有昵称／头像同步、资料只读及后端身份保护，不重复实现。普通客户账户入口为通行证 `/account`，管理员策略入口为 `/login/built-in`。
- 参考现有 `ProfileView`／`ProfileInfoCard`、`SettingsView`、管理员用户编辑／建号、SSO 策略和字段级用户更新模式。
- 本地注册、邮箱域名规则、注册邀请码／优惠码、本地找回密码不控制页内统一注册。在统一模式隐藏，保留底层值和非统一模式功能。
- 邮箱确认和 TOTP 仍服务本站管理员；SMTP、CAPTCHA、公开地址和首次建立网关账户的业务权益继续保留。
- 用户提供的 sub2api 备份中 130 个账户的本地 TOTP 均未启用，密钥与启用时间均空；不实施旧因素迁移或过渡界面。上线前检查实际数据库，不绕过或删除已有防护。
- 四份既有未跟踪部署记录保持原样，不纳入本次提交。现有 dujiao 未提交文件及 Casdoor 工作区保持原样。

## 当前修改

- 后端对普通客户身份字段、身份绑定和手动普通客户建号实施统一策略检查。角色变更不能绕过当前客户限制，混合身份／业务请求先拒绝再写入，配置读取失败禁止身份写入。
- 管理设置返回计算得到的只读 `sso_admin_url`，无有效 issuer 时不生成入口；不增加数据库设置。
- 后台区分通行证注册管理与本站管理员安全；隐藏控件不重置原值，网关公开地址与业务 SMTP 仍可编辑。
- 客户编辑不提交托管字段；建号对话框在统一模式只提供本地管理员。策略加载失败不开放身份编辑或建号。
- 个人中心在配置加载或失败时关闭本地编辑入口。

## 验证与下一步

后端针对性服务和 HTTP 回归已通过，覆盖普通客户／管理员、模式、角色绕过、混合字段、配置失败和后台链接。新策略及后台链接函数语句覆盖率均为 100%。前端 337 个测试文件、2584 个测试全部通过，类型检查、lint 和生产构建通过。后端全量 unit 测试仅两处响应基准因新增只读字段失败，更新后该 server 包全量通过。隐藏字段在保存时省略，由后端保留原始配置，避免重新格式化白名单。集成测试及嵌入前端的后端构建继续执行，PR CI 将执行完整流程。生产切换以完整备份、实际恢复验证、业务数据比较和零本地 MFA 检查为前提。
