# 页内认证独立化与 OIDC 跳转移除实施

日期：2026-10-03。用户授权覆盖商城及 API 网关的代码、PR、固定镜像发布和生产上线。

## 当前结论与依据

- 从两个 fork 的最新 main 创建 kano/remove-oidc-redirect；商城基线 a8ba284f，网关基线 ffc1f96b。
- 商城页内认证与 OIDC 共用配置、身份收尾和 handler；网关 SSO 依赖 oidc_connect 的地址及启用状态。配置迁移必须先于运行服务装配。
- 身份数据库中的 oidc 提供方标识及网关 issuer/subject 保留，以继续关联原业务用户和原权益规则。
- Casdoor 两应用的公开只读配置均未启用 CAPTCHA。新增页内 Default 图片及 Cloudflare Turnstile 接入，不改生产 CAPTCHA 策略。
- 参考现有密码代理、MFA 挑战、验证码注册、GORM 标记迁移、PostgreSQL 不可变迁移及配置部分更新模式。

## 实施与验证

按配置拆分、跳转链路删除、验证码接入、认证及迁移回归的小步顺序实施。记录测试、CI、发布及验收结果；只提交本次直接产生的文件，不修改任何预存未提交文件。

2026-10-07 本地验证结果：

- 独立 `sso_issuer_url` 与既有 SSO 开关、组织、应用字段；删除运行时 `oidc_connect_*` 设置及专用跳转实现，保留历史身份、issuer、subject 和权益提供方键。
- SQL 241 与启动事务共同完成一次性配置转换。真实 PostgreSQL 覆盖新旧数据库、显式空值/关闭、运行配置优先级、重复启动、并发启动、错误回滚及已迁移配置缺失时拒绝认证。真实 Redis 覆盖挑战原子消费与并发重放。
- 注册、登录和发码分别绑定五分钟图片/Turnstile 挑战；密码保留原字符，MFA 未完成前无会话。旧 OIDC pending 会话及删除接口均无法签发凭据。
- 全量 Go 单测、`go vet ./...`、嵌入前端构建通过；前端全量 2,573 项测试、类型检查、生产构建和 ESLint 通过。随后修改的真实路由守卫和验证码回归 62 项通过，验证码前端逻辑覆盖率 97.75%，分支 95.58%，函数 100%。后端 Casdoor 客户端及验证码引擎 race 覆盖率分别 94.6%、93.3%。
- 隔离 Chrome 验证商城三模板和网关的图片/Turnstile/无验证码登录、MFA、注册；本站和通行证验证证明分别提交，旧回调显示 404。网关后台保存只提交独立 SSO 配置，不再包含跳转字段。浏览器发现的旧回调被守卫重定向问题已修复，并覆盖普通、管理员、匿名及后台模式。
- 生产只读核对：网关 `v0.2.11-kano.7` 与商城 `v0.1.0-kano.18` 正常运行。发布与迁移尚未执行；后续结果另记发布记录。
- 两站后台独立通行证设置在隔离 Chrome 中完成实际保存，商城仅提交六字段配置。三套商城模板、网关与后台截图已人工查看。
